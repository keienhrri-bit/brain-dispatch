## Goal
One or two sentences: what is needed, and what the brain will use it for.

## Background
Facts and conventions already settled. Paths already ruled out. No conversation history.

## Input
Which files or directories to read (short paths, relative to the working directory or a read-only directory). Say so if a file is too large to read whole.

## Output
Which file to write in the working directory, in what format, with which columns, how long.

## Done when
What counts as finished, and how the worker should check itself: go back to the source for line numbers, assert totals in the script, and so on.

## Boundaries
What not to do. The user's own constraints, copied word for word. Anything uncertain goes into `open`, not into a guess.
